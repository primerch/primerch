# Reacher profile visual system

The direction is a precise, bold contributor portfolio. A custom REACHER wordmark and a branching drawing of real upstream fixes carry the identity. The surrounding GitHub interface stays native.

## Palette

| Role | Dark | Light |
| --- | --- | --- |
| Canvas | `#080e18` | `#f5f8fc` |
| Panel | `#0d1523` | `#ffffff` |
| Primary text | `#edf4fc` | `#102238` |
| Secondary text | `#a4b6cb` | `#50647d` |
| Accent | `#79ffe1` | `#086b57` |
| Hairline | `#26364c` | `#d5dfeb` |

The accent identifies contribution paths and selected data. It is not spread over every label or surface. No glow, decorative gradient, infinite animation, fake terminal, or invented performance rank.

## Typography and composition

- Space Grotesk provides the outlined wordmark; its original SIL Open Font License is retained. GitHub's native UI font owns readable body copy.
- The first region is a large wordmark with an asymmetric branch drawing, followed by a short, specific statement.
- Actual metrics follow: lifetime contributions, anonymous private activity, and open-source outcomes. Time windows and public/private scope are explicit.
- Portfolio names use a shared typographic treatment. Their descriptions match the approved product facts.
- Cards have 12px corners, quiet borders, no shadows, and consistent internal spacing.
- On narrow screens, the hero gets its own composition and stats cards stack. Every plotted value also has readable text or an accessible description.
- Static information remains static. The branch illustration explains provenance without looping motion.
